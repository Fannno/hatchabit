# Hatchabit

> 和小小夥伴一起慢慢長大

Hatchabit 是一款以電子寵物養成為核心的互動式 Web App。玩家會從神秘蛋中遇見自己的「小 Bit」，並透過餵食、摸摸、戳戳、洗澡、睡眠與小遊戲等方式陪伴牠成長。

本專案以單一 `index.html` 完成主要遊戲功能，不使用後端，遊戲進度儲存在瀏覽器的 LocalStorage 中，並可直接部署至 GitHub Pages。

## 小 Bit 世界觀

Hatchabit 世界中的電子寵物統稱為「小 Bit」。每隻小 Bit 都會從神秘蛋中孵化，擁有自己的種類、個性、名字、等級與生活狀態。

目前共有六種小 Bit：

- 貓
- 狗
- 企鵝
- 狐狸
- 龍
- 小怪獸

每隻小 Bit 會隨機擁有一種個性：

- 貪吃：飽食下降較快，餵食可得到較多親密度
- 愛玩：玩具與小遊戲的心情收益較高
- 愛睡：睡眠時體力恢復較快
- 愛乾淨：髒時心情較容易下降，洗澡收益較高
- 黏人：摸摸時可得到較多親密度
- 調皮：戳戳或玩具互動可能觸發特殊反應

## 第一次進入 Hatchabit

第一次進入遊戲時，系統不會立刻顯示選蛋畫面，而會先提醒玩家遊戲進度保存在目前瀏覽器中。

如果使用無痕／私人瀏覽模式、清除網站資料、更換瀏覽器、裝置或網站網址，遊戲紀錄可能消失或無法共用，因此建議使用一般瀏覽模式遊玩。

同一個介紹畫面也會說明如何將 Hatchabit 加入手機主畫面：

- iPhone / iPad：Safari → 分享 → 加入主畫面 → 加入
- Android：Chrome → 選單 → 加入主畫面／安裝應用程式

若已經以主畫面 Web App 模式開啟，系統不會重複顯示加入主畫面的操作教學。

## 選蛋與命名

進入選蛋流程後會隨機出現三顆神秘蛋。蛋可能具有星星、斑點、波浪、愛心或彩色花紋，但花紋不代表裡面的小 Bit 種類。

孵化完成後會先顯示：

- 小 Bit 外觀
- 種類
- 個性
- 個性效果

此時可以選擇「再選一次」或「就是牠了」。確認後才會進入命名畫面。

名字最多 16 個字；若直接留白送出，系統會自動將名字設定為「小 Bit」。

第一隻小 Bit 完成命名並正式進入小屋後，系統會一次性贈送 200 金幣作為新手歡迎禮，重新整理頁面不會重複領取。

## 日常照顧

小 Bit 共有六項主要狀態，數值範圍皆為 0～100：

- 飽食度
- 心情值
- 清潔度
- 體力值
- 健康度
- 親密度

主要互動包含：

### 餵食

從背包選擇已購買的食物或道具。不同食物會帶來不同的狀態效果。

### 摸摸

在小 Bit 本體上按住滑動一小段距離，即判定為摸摸。

- 電腦：滑鼠拖曳
- 手機／平板：手指滑動
- 摸摸收益冷卻：30 秒

### 戳戳

快速點一下小 Bit 本體的任何位置，即判定為戳戳，不再限制特定肚子區域。

- 戳戳收益冷卻：15 秒
- 與摸摸共用同一套 Pointer Events 手勢判斷，同一次操作只會觸發其中一種

### 洗澡

提升清潔度與心情；愛乾淨個性可獲得額外心情收益。

### 睡眠

睡眠不是立即補滿體力，而是依照實際經過時間慢慢恢復。愛睡個性的恢復速度更快。

## 真實時間與離線計算

Hatchabit 會記錄最後更新時間，即使關閉網頁，小 Bit 的狀態仍會依實際經過時間變化。

一般狀態的基準大致為：

- 飽食：每小時 −2
- 心情：每小時 −1
- 清潔：每小時 −1
- 體力：依活動與睡眠狀態計算
- 親密度：非常緩慢下降

系統不會因為短時間沒有開啟遊戲就給予過重懲罰。

## 健康度

健康度是綜合照顧結果。當飽食、清潔與體力長時間過低時會慢慢下降；主要狀態保持良好時則會逐漸恢復。

## 成長與等級

小 Bit 的最高等級為 LV.99。

下一級所需經驗值：

```text
目前等級 × 20 EXP
```

成長分為四個階段：

| 等級 | 階段 |
| --- | --- |
| LV.1～4 | 幼年期 |
| LV.5～9 | 成長期 |
| LV.10～19 | 青年期 |
| LV.20～99 | 成年期 |

六種小 Bit 都有四階段外觀。成長不只使用放大縮小或額外配件，而會改變頭身比例、輪廓、四肢、耳朵、角、尾巴、翅膀等物種特徵。

其中「龍」取代舊版史萊姆，會從圓潤幼龍逐步長出更明顯的角、尾巴、翅膀與爪子。

## 金幣

金幣可以用於購買食物、特殊道具、玩具、家具、房間主題與新房間。

取得方式包含：

- 第一次正式進入遊戲的新手歡迎禮：200 金幣
- 每日陪伴獎勵
- 完成三款小遊戲
- 小 Bit 升級
- 高等級里程碑獎勵

正式進入遊戲後，可以直接點擊右上角的金幣餘額查看取得方式。

## 休息模式

暫時沒有時間照顧的小 Bit 可以進入休息模式。

休息期間：

- 六項狀態凍結
- 不會因低狀態生病
- 不累積 EXP
- 不參與活動

恢復照顧後重新開始計時。休息模式不是刪除小 Bit，也不是額外房間。

## 小遊戲

目前有三款小遊戲：

### 接接樂

控制小 Bit 左右移動，接住掉落的金幣、蘋果與飯糰等物品，約 30 秒，完成後可獲得約 10～50 金幣。

### 記憶翻牌

找出六組相同圖案，完成越快獎勵越高，約可獲得 20～60 金幣。

### 快速點擊

快速點擊出現的小 Bit，同時避開炸彈，約 30 秒，可獲得約 10～50 金幣。

每局開始會消耗 8 點體力，完成後可以獲得金幣、EXP、心情與親密度。

## 每日陪伴獎勵

每天可以領取一次：

```text
50 → 60 → 70 → 80 → 90 → 100 → 150
```

完成七次後重新循環，漏掉一天不會讓進度歸零。

## 視覺與操作設計

Hatchabit 的系統介面以低飽和霧藍、奶藍與藍灰色為主，小屋場景則使用較溫暖的自然配色，避免整個畫面都變成相同藍灰色。

首頁採用上下分區：

- 上半部固定顯示 Header、小 Bit 資訊、EXP、房間與小 Bit
- 從餵食／摸摸／戳戳／洗澡／睡眠操作列開始，才是可獨立向下捲動的區域
- 底部導覽列固定在畫面底部

EXP 與六項狀態條皆採用較細的樣式，讓小 Bit 保持為主要視覺焦點。

網站左上角使用 Hatchabit 專屬品牌角色「Bit」作為 inline SVG Logo。Logo 與玩家可飼養的六種小 Bit 分開，不使用 Emoji、外部圖片或第三方圖示套件。

## 行動裝置

Hatchabit 針對手機與桌面進行 Responsive 設計，並使用 Pointer Events 同時支援滑鼠、觸控與觸控筆。

為避免縮放手勢干擾摸摸、戳戳與小遊戲，本版 viewport 關閉使用者縮放。

同時加入 iOS Web App 相關 meta 設定，從 Safari 加入主畫面後可用較接近獨立 Web App 的方式開啟。目前沒有加入 Service Worker，因此不是完整離線安裝式 PWA。

遊戲資料保存在瀏覽器 LocalStorage，包括：

- 金幣與累積收入
- 房間
- 小 Bit 種類、名字、個性
- 等級與 EXP
- 六項狀態
- 背包
- 已購買玩具、家具與主題
- 成就
- 小遊戲紀錄
- 每日獎勵
- 睡眠與休息狀態
- 最後更新時間
- 新手說明是否已看過
- 新手 200 金幣是否已發放

不需要建立帳號或連接後端。
