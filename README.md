# Hatchabit

> 和小小夥伴一起慢慢長大

Hatchabit 是一款以電子寵物養成為核心的互動式 Web App。玩家會從神秘蛋中遇見自己的「小 Bit」，並透過餵食、摸摸、戳戳、洗澡、睡眠、房間佈置與 Bit 遊樂場等方式陪伴牠成長。

目前主要功能集中於單一 `index.html` 中，不需要後端伺服器，遊戲進度保存在瀏覽器的 LocalStorage，並可直接部署至 GitHub Pages。

## 專案名稱

專案名稱：**Hatchabit**

名稱由 **Hatch** 與 **Habit** 兩個英文單字組合而成：

- **Hatch**：孵化，對應遊戲一開始從三顆蛋中選擇一顆，並將小 Bit 孵化出來的初次相遇流程。
- **Habit**：習慣，對應玩家每天回來餵食、摸摸、洗澡、玩遊戲與照顧小 Bit，陪伴牠慢慢長大的養成習慣。

因此，Hatchabit 想表達的是從「孵化」開始，透過每天一點一點的陪伴與照顧，逐漸建立與小 Bit 一起成長的日常習慣。

## 小 Bit 世界觀

Hatchabit 世界中的電子寵物統稱為「小 Bit」。每隻小 Bit 都會從神秘蛋中孵化，擁有自己的種類、個性、名字、等級與生活狀態。

目前共有六種小 Bit：

- 貓
- 狗
- 企鵝
- 狐狸
- 龍
- 小怪獸

每隻小 Bit 會隨機擁有一種個性：

- 貪吃：飽食下降較快，餵食可得到較多親密度
- 愛玩：玩具與小遊戲的心情收益較高
- 愛睡：睡眠時體力恢復較快
- 愛乾淨：髒時心情較容易下降，洗澡收益較高
- 黏人：摸摸時可得到較多親密度
- 調皮：戳戳或玩具互動可能觸發特殊反應

## 第一次進入 Hatchabit

第一次進入遊戲時，系統會先提醒玩家：遊戲進度保存在目前瀏覽器中。

如果使用無痕／私人瀏覽模式、清除網站資料、更換瀏覽器、裝置或網站網址，進度可能消失或無法共用，因此建議使用一般瀏覽模式遊玩。

同一個介紹畫面也會說明如何將 Hatchabit 加入手機主畫面：

- iPhone / iPad：Safari → 分享 → 加入主畫面 → 加入
- Android：Chrome → 選單 → 加入主畫面／安裝應用程式

若已經以主畫面 Web App 模式開啟，系統會改為顯示目前已從主畫面開啟，而不重複教學。

## 選蛋與命名

開始遊戲後會隨機出現三顆神秘蛋。蛋可能具有星星、斑點、波浪、愛心或彩色花紋，但花紋不代表裡面的小 Bit 種類。

孵化後會先顯示：

- 小 Bit 外觀
- 種類
- 個性
- 個性效果

玩家可以選擇「再選一次」或「就是牠了」。正式確認後才會進入命名畫面。

名字最多 16 個字；若留白直接確認，系統會自動命名為「小 Bit」。

第一隻小 Bit 完成命名並正式進入小屋後，系統只會發放一次 200 金幣新手歡迎禮，重新整理不會重複領取。

## 日常照顧

小 Bit 共有六項主要狀態，範圍皆為 0～100：

- 飽食度
- 心情值
- 清潔度
- 體力值
- 健康度
- 親密度

### 餵食

從背包選擇已購買的食物後，食物會直接出現在小屋畫面中，小 Bit 會播放約 3 秒的吃東西動畫，食物會逐步縮小直到吃完。

不同食物具有不同狀態效果；奇蹟特效藥則維持獨立的特殊恢復效果。

### 摸摸

在小 Bit 本體上按住並滑動一小段距離，即判定為摸摸。

- 電腦：滑鼠拖曳
- 手機／平板：手指滑動
- 摸摸期間小 Bit 會閉上眼睛並輕微晃動
- 黏人個性可得到額外親密度
- 摸摸收益冷卻：30 秒

### 戳戳

快速點一下小 Bit 本體的任何位置，即判定為戳戳。

戳戳後小 Bit 會短暫壓縮、彈動並露出驚訝表情，同時出現驚嘆號反應。調皮個性仍保留特殊反應機率。

- 戳戳收益冷卻：15 秒
- 與摸摸共用 Pointer Events 手勢判斷
- 同一次操作只會觸發摸摸或戳戳其中一種

### 洗澡

洗澡改為兩階段互動：

1. 蓮蓬頭從上方出現，向下沖水並產生泡泡
2. 水停後出現浴巾，玩家需要用滑鼠或手指拖動浴巾幫小 Bit 擦乾

擦乾完成後才正式套用清潔度、心情與 EXP 收益。畫面也提供「完成擦乾」按鈕作為鍵盤與操作備援。

### 睡眠

睡眠仍依真實時間慢慢恢復體力，不是立即補滿。

如果目前房間有放置「好夢小床」，小 Bit 睡覺時會移到床上並閉眼休息；若房間沒有床，則維持原本在房間中央的睡眠方式。

愛睡個性的體力恢復速度較快。

## 真實時間與離線計算

Hatchabit 會記錄最後更新時間，即使關閉網頁，小 Bit 的狀態仍會依實際經過時間變化。

一般狀態的基準大致為：

- 飽食：每小時 −2
- 心情：每小時 −1
- 清潔：每小時 −1
- 體力：依活動與睡眠狀態計算
- 親密度：非常緩慢下降

系統不會因為短時間沒有開啟遊戲就給予過重懲罰。

## 健康度

健康度是綜合照顧結果。當飽食、清潔與體力長時間過低時會慢慢下降；主要狀態維持良好時則會逐漸恢復。

首頁固定區的狀態提示會優先顯示目前較需要處理的項目，避免一次列出過多資訊。

## 成長與等級

小 Bit 的最高等級為 LV.99。

下一級所需經驗值：

```text
目前等級 × 20 EXP
```

成長分為四個階段：

| 等級 | 階段 |
| --- | --- |
| LV.1～4 | 幼年期 |
| LV.5～9 | 成長期 |
| LV.10～19 | 青年期 |
| LV.20～99 | 成年期 |

六種小 Bit 都有四階段外觀。成長不只使用放大縮小或額外配件，而會改變頭身比例、輪廓、四肢、耳朵、角、尾巴、翅膀等物種特徵。

龍取代舊版史萊姆，會從圓潤幼龍逐步長出更明顯的角、尾巴、翅膀與爪子。企鵝的臉部表情位置也在 V3 起重新調整。

正式進入遊戲後，可以直接點擊右上角的金幣餘額查看取得方式。

## 休息模式

暫時沒有時間照顧的小 Bit 可以進入休息模式。

休息期間：

- 六項狀態凍結
- 不會因低狀態生病
- 不累積 EXP
- 不參與活動

恢復照顧後重新開始計時。休息模式不是刪除小 Bit，也不是額外房間。

## Bit 遊樂場

遊戲頁正式命名為「Bit 遊樂場」，目前共有四款遊戲。

### Bit 接到了！

小 Bit 會拿著碗左右移動，接住從天而降的金幣、蘋果與飯糰。

V4 將接取基準線下移，讓角色可以從地面線上方突出，並以碗作為實際接取視覺。

- 約 30 秒
- 獎勵約 10～50 金幣

### Bit 配對趣

翻開卡片，找出六組相同的小 Bit 世界圖案。

- 完成越快，獎勵越高
- 約 20～60 金幣

### Bit 快閃！

快速點擊九宮格中出現的小 Bit，同時避開炸彈。

V4 將九宮格尺寸固定為 3 × 3，角色與炸彈出現／消失時不會再改變格子大小或造成 layout shift。

- 約 30 秒
- 約 10～50 金幣

### Bit 吃不停！

Hatchabit 版本的貪食蛇玩法。

玩家控制小 Bit 在 12 × 12 格子中移動，吃到食物後尾巴會逐漸變長；碰到邊界或自己的尾巴就會結束。

操作方式：

- 手機／平板：在遊戲格子中向上下左右滑動
- 電腦：方向鍵或 WASD

- 約 30 秒
- 約 10～60 金幣

四款遊戲每局開始皆消耗 8 點體力，完成後可獲得金幣、EXP、心情與親密度。

## 視覺與操作設計

Hatchabit 的系統介面以低飽和霧藍、奶藍與藍灰色為主，小屋場景則使用較溫暖的自然配色。

### 固定品牌列

首頁、商店、Bit 遊樂場與小 Bit 頁面共用相同尺寸的品牌列。

品牌列會固定在頁面最上方，包含：

- Bit 品牌角色 Logo
- Hatchabit 名稱
- 「和小小夥伴一起慢慢長大」標語
- 遊玩說明
- 金幣餘額

切換不同分頁時不會再出現 Header 大小不一致的情況，向下滑動其他頁面時品牌列仍會保留在頂端。

### 首頁上下分區

首頁採固定區與可捲動區分離：

- 上半部固定顯示小 Bit 資訊、EXP、房間與小 Bit
- 房間固定區和下方操作區之間加入一條獨立的安全分隔帶
- 從餵食／摸摸／戳戳／洗澡／睡眠操作列開始才是可獨立向下捲動區
- 底部導覽列固定在畫面底部

這個分隔讓下方內容滑動時不會直接貼著房間場景，看起來更像兩個清楚的介面區域。

### 狀態訊息

畫面上方的 Toast 提示同時間最多保留 3 條；相同訊息再次出現時會取代舊訊息，避免短時間內堆滿手機畫面。

## 行動裝置

Hatchabit 針對手機與桌面進行 Responsive 設計，並使用 Pointer Events 同時支援滑鼠、觸控與觸控筆。

為避免縮放手勢干擾摸摸、戳戳、洗澡擦乾與小遊戲，本版 viewport 關閉使用者縮放。

同時加入 iOS Web App 相關 meta 設定，從 Safari 加入主畫面後可用較接近獨立 Web App 的方式開啟。目前沒有加入 Service Worker，因此不是完整離線安裝式 PWA。

- 小 Bit 種類、名字、個性
- 等級與 EXP
- 六項狀態
- 背包
- 已購買玩具、家具與主題
- 成就
- 四款 Bit 遊戲紀錄
- 每日獎勵
- 睡眠與休息狀態
- 最後更新時間
- 新手說明是否已看過
- 新手 200 金幣是否已發放

舊版只有三款遊戲的存檔在載入時會自動補上 `snake` 遊戲紀錄，不需要清除原本進度。
