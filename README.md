> 和小小夥伴一起慢慢長大

Hatchabit 是一款以電子寵物養成為核心的互動式 Web App。玩家會從神秘蛋中遇見自己的第一隻「小 Bit」，透過餵食、摸摸、戳戳、洗澡、睡眠與小遊戲陪伴牠成長，也可以收集不同種類的小 Bit、佈置房間、收藏紀念品，或在忙碌時請保母協助照顧。

本專案以 Vibe Coding 方式開發，主要程式集中在單一 `index.html`，不需要後端服務或帳號。遊戲進度保存在目前瀏覽器的 LocalStorage。

## 線上遊玩

## 專案名稱

Hatchabit 由 **Hatch** 與 **Habit** 組合而成：

- **Hatch**：孵化。玩家從神秘蛋中選擇一顆，遇見自己的小 Bit。
- **Habit**：習慣。玩家每天回來照顧、陪玩與觀察小 Bit 的成長，慢慢建立陪伴的日常。

## 遊戲世界與角色

Hatchabit 世界中的電子寵物統稱為「小 Bit」。每隻小 Bit 都有自己的名字、種類、個性、等級與生活狀態。

### 六種類型

- 貓
- 狗
- 企鵝
- 狐狸
- 龍
- 小怪獸

每種類型皆有幼年期、成長期、青年期與成年期四種外觀，共 24 種成長造型。成長不只放大角色或更換配件，也會改變頭身比例、輪廓、四肢及各物種的耳朵、尾巴、角或翅膀等特徵。

### 六種個性

| 個性 | 效果 |
| --- | --- |
| 貪吃 | 飽食度下降速度增加 30%；有效餵食可獲得額外親密度。 |
| 愛玩 | 玩具與小遊戲的心情收益增加 40%。 |
| 愛睡 | 睡眠時體力恢復速度增加 50%。 |
| 愛乾淨 | 清潔度低時心情下降較快；洗澡的心情收益增加 50%。 |
| 黏人 | 摸摸時可獲得較多親密度。 |
| 調皮 | 戳戳或玩具互動可能觸發額外反應。 |

## 初次進入與孵化流程

第一次進入 Hatchabit 時，系統會先說明遊戲進度保存在目前瀏覽器，以及如何將網站加入手機主畫面。

- iPhone／iPad：使用 Safari 開啟網站，選擇「分享 → 加入主畫面 → 加入」。
- Android：使用 Chrome 開啟網站，從選單選擇「加入主畫面」或「安裝應用程式」（顯示項目依瀏覽器版本而異）。

接著玩家會看到三顆隨機神秘蛋。蛋的星星、斑點、波浪、愛心或彩色花紋不代表小 Bit 的種類。孵化後可以查看種類與個性，再選擇重新抽選或確認。確認後可為小 Bit 命名，名稱最多 16 個字；如果留白，會自動命名為「小 Bit」。

第一隻小 Bit 完成命名並正式進入小屋後，會一次獲得 **200 金幣新手歡迎禮**。重新整理不會重複領取。

## 日常照顧

### 六項狀態

所有狀態介於 0～100：

- **飽食度**：反映是否吃飽。
- **心情值**：反映心情與陪玩狀況。
- **清潔度**：透過洗澡維持。
- **體力值**：會隨活動消耗，睡眠時逐漸恢復。
- **健康度**：主要狀態良好時逐漸恢復；飽食、清潔或體力長時間過低時可能下降。
- **親密度**：透過日常照顧、摸摸、玩具與小遊戲累積，並會非常緩慢地下降。

一般狀態的基礎時間變化約為每小時飽食度 −2、心情值 −1、清潔度 −1、體力值 −0.4、親密度 −0.05。貪吃個性會加快飽食度下降。關閉網頁後，系統會依最後更新時間計算狀態變化。

### 餵食

玩家先在商店購買食物，再從背包選擇使用。餵食時，食物會出現在小屋中並播放進食動畫。

| 食物／道具 | 價格 | 效果 |
| --- | ---: | --- |
| 基本飼料 | 10 | 飽食度 +15 |
| 蘋果 | 20 | 飽食度 +20、健康度 +2 |
| 飯糰 | 35 | 飽食度 +30 |
| 布丁 | 50 | 飽食度 +15、心情值 +10 |
| 草莓蛋糕 | 80 | 飽食度 +25、心情值 +20、親密度 +2 |
| 奇蹟特效藥 | 1500 | 使用後將六項狀態全部恢復至 100 |

有效餵食的照顧收益有 60 秒冷卻；冷卻期間仍可使用食物，但不會重複取得該次照顧收益。

### 摸摸與戳戳

- **摸摸**：在小 Bit 本體上按住並滑動一小段距離。角色會閉眼放鬆並做出互動反應，收益冷卻 30 秒。
- **戳戳**：快速點擊小 Bit 本體任何位置。角色會出現驚訝表情與短暫彈動，收益冷卻 15 秒。
- 同一次指標操作只會判定為摸摸或戳戳其中一種，不會在摸摸結束後再觸發戳戳。
- 電腦使用滑鼠；手機與平板使用手指。角色也支援鍵盤操作：先選取角色後，空白鍵摸摸、Enter 戳戳。

### 洗澡

洗澡會先顯示蓮蓬頭沖水與泡泡，再進入擦乾階段。玩家需要拖動浴巾擦過小 Bit 身上的水珠；完成擦乾後才會套用清潔度、心情與經驗收益。洗澡收益冷卻 3 分鐘。

### 睡眠

手動睡眠會依真實時間恢復體力，不會立即補滿。愛睡個性的體力恢復速度較快。若房間放置「好夢小床」，小 Bit 會先走向床鋪、依床頭方向躺下，並蓋上只覆蓋身體下半部的被子。

### 夜間自動入睡

「我的小 Bit」頁面提供夜間自動入睡開關，預設開啟：

- 每晚 **23:00** 自動入睡。
- 每天早上 **07:00** 自動醒來。
- 休息模式中的小 Bit 不會套用自動睡眠。
- 玩家若手動叫醒自動睡著的小 Bit，當晚會暫停自動入睡至 07:00。
- 關閉網頁期間也會依實際時間計算睡眠與體力恢復。

### 保母服務

如果當天忙碌、無法親自照顧，可以替每隻小 Bit 每天聘請一次保母。聘請後會立即進入獨立的保母照護畫面，保母角色會從飛碟降落，並靠近小 Bit，以滾球、角色動作與互動對話呈現陪玩過程。

- 保母服務從聘請當下開始，最晚照顧到當天 **20:00**；20:00 後不能再聘請當日保母。
- 費用依剩餘服務時間調整，最低 **60 金幣**、最高 **180 金幣**；完整 12 小時服務費用為 180 金幣。
- 照護期間會鎖定其他遊戲操作，畫面只保留「結束小 Bit 照護」按鈕。玩家可以提前結束，但不退還已支付的金幣，該隻小 Bit 當天也不能再次聘請保母。
- 保母每 **5 分鐘**完成一次照護：飽食度 **+3**、心情值 **+2**、清潔度 **+2**、體力值 **+3**、健康度 **+1**，各項數值不會超過 100。
- 照護期間不會扣除六項狀態，也不會增加 EXP 或親密度；保母不會代替玩家領取每日陪伴獎勵。
- 休息中或睡眠中的小 Bit 不能聘請保母，需先恢復照顧或叫醒牠。
- 關閉頁面或重新開啟後，保母服務仍會依實際時間持續計算；若服務已結束，畫面會回到一般遊戲。

## 親密禮物與紀念品

親密度除了代表玩家與小 Bit 的關係，也會解鎖驚喜：

- 親密度達到 **80 以上**時，成功的照顧互動有機會觸發驚喜禮物。每 24 小時最多觸發一次，內容為 50 金幣或紀念品。
- 親密度達到 **100**時，每天可收到一份每日禮物，內容為 100 金幣或尚未收藏的紀念品。
- 紀念品包含小 Bit 的緞帶、星星徽章、晴天葉片、小海貝與小鈴鐺，可在「我的小 Bit」頁面查看收藏進度。
- 每件紀念品只收藏一次；若已收齊，後續禮物會折換成金幣。

## 金幣與每日獎勵

金幣可用於購買食物、玩具、家具、主題、新房間與保母服務。

主要收入來源：

- 第一次正式進入小屋的新手歡迎禮：200 金幣。
- 每日陪伴獎勵：**60 → 70 → 80 → 90 → 100 → 120 → 180** 金幣，七次後重新循環；漏領一天不會讓累計進度歸零。
- Bit 遊樂場結算：依星級獲得 **20／40／60** 金幣。
- 一般升級：12 金幣。
- LV.30 起，每逢十級里程碑：120 金幣。
- 親密禮物：依親密度與紀念品收藏情況獲得金幣或紀念品。

右上角的金幣餘額可以點擊，查看金幣來源與目前收入方式。

## Bit 遊樂場

目前有四款小遊戲，每款皆可選擇簡單、普通或困難。難度會影響掉落速度、目標出現速度、翻牌記憶時間或移動速度。每局開始會消耗 8 點體力，完成後會增加 EXP、心情與親密度，並依星級發放金幣。

### Bit 接到了！

控制小 Bit 左右移動，接住從上方掉落的金幣、蘋果與飯糰。可使用方向鍵、畫面左右按鈕或在遊戲區拖曳移動。

### Bit 配對趣

翻開卡片，找出六組相同圖案。難度越高，翻錯後卡片留給玩家記憶的時間越短。

### Bit 快閃！

在九宮格中快速點擊小 Bit 得分，同時避開炸彈。難度越高，目標出現速度越快，炸彈比例也會提高。

### Bit 吃不停！

控制小 Bit 在 12 × 12 格子中移動並吃到食物，身體會逐漸變長；撞到邊界或自己的尾巴就會結束。手機可在格子上滑動，或使用畫面下方的左轉／右轉按鈕；電腦可使用方向鍵或 WASD。

### 遊戲時間與星級

- 計時遊戲：簡單 20 秒、普通 18 秒、困難 15 秒。
- Bit 配對趣：完成六組配對時結束。
- 一星：20 金幣；二星：40 金幣；三星：60 金幣。
- 中途離開不會取得完成獎勵，已消耗的體力也不會退還。

## 休息模式

在「我的小 Bit」頁面可以讓單隻小 Bit 暫時休息。休息期間六項狀態凍結，不會因低狀態生病，也不累積 EXP。恢復照顧後重新開始計時。休息模式不是刪除角色，也不是額外房間。

## 視覺與技術實作

Hatchabit 的系統介面以低飽和霧藍、奶藍與藍灰色為主，小屋場景使用較溫暖的自然配色。角色、蛋、物件、介面圖示與品牌角色使用程式內嵌 SVG 與 CSS 繪製，不載入第三方角色圖片、外部圖示套件或素材包；角色互動使用分層 SVG、表情狀態與 CSS 動畫。

主要技術：

- HTML
- CSS
- Vanilla JavaScript
- Inline SVG
- LocalStorage
- Pointer Events

本專案沒有後端 API。遊戲資料只保存在目前瀏覽器，無痕／私人瀏覽、清除網站資料、更換瀏覽器、裝置或網址都可能讓進度消失或無法共用。

網站有加入 iOS Web App 相關 meta 設定，可從 Safari 加入主畫面，以較接近獨立 Web App 的方式開啟。目前沒有 Service Worker，因此不屬於完整離線安裝式 PWA。

## 執行方式

直接以瀏覽器開啟 `index.html` 即可遊玩。部署至 GitHub Pages 時，將 `index.html` 與 `README.md` 放在 repository 根目錄。

## Vibe Coding 開發方式

本專案透過與生成式 AI 反覆討論、產生程式、查看畫面與修正問題完成。角色造型、互動狀態、介面流程與遊戲數值皆依實際測試結果逐步調整，而不是只在一次 Prompt 後直接交付。
